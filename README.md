# AIクリスタ漫画スタジオ v0.2

iPad Safari向けのオフラインHTMLプロトタイプです。`index.html` をHTTPSホスティング（GitHub Pages等）に置いてSafariで開くことを推奨します。iPadの「ファイル」から直接開くとブラウザの制約で保存や操作が機能しない場合があります。

## 実装済み
- 複数作品の作成・選択
- あらすじ、ジャンル、世界観、脚本の入力と自動保存（localStorage）
- 作品専用・共通アセットの登録と相互コピー
- アセット参照画像をIndexedDBに保存（ブラウザ内のみ）
- 5レイヤーの表示切替と簡易ペン描画、プレビューPNG出力
- 作品テキスト・アセットメタデータのJSONバックアップ

## 未実装・制限
- JSONバックアップにはアセット画像バイナリが含まれません。ブラウザデータ削除で画像は失われます。
- 原稿編集は860×1214の簡易プレビューのみで、レイヤーごとの正確な消去、保存、600dpi出力は未実装です。
- AI生成、領域分離、背景補完、吹き出しテンプレートの実編集、クリスタ向けレイヤー出力は未実装です。
- ブラウザ内ストレージは長期保存の保証がありません。重要データは別途バックアップしてください。
